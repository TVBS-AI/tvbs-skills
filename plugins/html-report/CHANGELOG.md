# Changelog

## [0.1.0] - 2026-11-07
### Added
- Initial release：AI 只寫 Markdown 稿，內附的 CLI 排版、畫流程圖／時序圖／ER 圖／樹狀圖／時間軸／圖表，產出不連外、可離線打開的單一 HTML 報告，可直接上傳 company-wiki
- 繁體中文的 SKILL.md：何時做成頁面、執行與讀輸出的方式、依資訊形狀選元件、寫作原則、`patch` 只改一區、讀者回覆的處理、上傳 wiki 前要說明內嵌了哪些檔案
- `references/format.md`（所有元件、程式碼、圖片、數學式、語言的完整中文說明）與 `references/settings.md`（設定、清理、更新）
- 排版引擎改自 [answer-me-with-html](https://github.com/doggy8088/answer-me-with-html) v0.5.11（MIT）：頁首不再有「Generated by … ★ Star on GitHub」署名、不再到 GitHub 檢查新版本、資料夾改用 `~/.tvbs-html-report`；`build/` 可重現建置並跑原專案測試
